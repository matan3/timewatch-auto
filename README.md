# דיווח שעות אוטומטי ל-TimeWatch

הסקריפט רץ בימים א'-ה' בשעה אקראית בין 20:00 ל-21:00 על השרתים של GitHub (בחינם, בלי מחשב).
הוא נכנס ל-TimeWatch וממלא את היום אם הוא מסומן "חסרה כניסה/יציאה".

**מה הוא ממלא:** כניסה בשעה אקראית בין 09:00 ל-09:20, יציאה 9 שעות אחרי.
פרויקט ומיקום (שדה ההערה) מועתקים מאותו יום בשבוע שעבר – כך שאין צורך להגדיר כלום.

**הגנות:**
- לא נוגע ביום שכבר יש בו שעות, היעדרות (חופש/מחלה/מילואים) או הערה – ושולח התראה לבדיקה.
- אף פעם לא שישי/שבת, ואף פעם לא ימים עתידיים.
- אחרי כל עדכון קורא את היום בחזרה כדי לוודא שנשמר.
- **חופש/מחלה צריך לדווח באפליקציה לפני 20:00.**

---

## הקמה לעצמך (מהטלפון, ~10 דקות)

כל ההגדרות נעשות ב-**Safari** (לא באפליקציה של GitHub).

1. **חשבון GitHub** – אם אין, פותחים ב-github.com.
2. **העתקת המאגר** – נכנסים לדף המאגר הזה ולוחצים **Fork** ← **Create fork**.
3. **הפעלת Actions** – במאגר החדש שלך: לשונית **Actions** ← לוחצים על הכפתור הירוק ("I understand my workflows…").
   אחר כך בוחרים **TimeWatch daily report** ← **Enable workflow** (אם מופיע).
4. **הפרטים שלך** – `Settings` ← `Secrets and variables` ← `Actions` ← **New repository secret**, שלושה סודות:

   | Name | Secret |
   |---|---|
   | `TW_COMPANY` | מספר חברה |
   | `TW_EMPLOYEE` | מספר עובד |
   | `TW_PASSWORD` | סיסמה ל-TimeWatch |

5. **התראות לאייפון (מומלץ)** – מתקינים את האפליקציה **ntfy**, לוחצים **+** ונרשמים לשם ערוץ אקראי שרק אתה יודע
   (למשל `tw-` ועוד 12 אותיות/ספרות אקראיות). מוסיפים אותו כסוד רביעי: `NTFY_TOPIC`.
6. **בדיקה** – `Actions` ← **TimeWatch daily report** ← **Run workflow** (להשאיר **Dry run** מסומן).
   בריצה ← `report` ← `Report hours` תראה מה הוא *היה* מדווח, בלי לשנות כלום.
   בטלפון: אם הכפתור לא מופיע, ב-Safari ‏**aA** ← "בקשת אתר מחשב שולחני".

זהו – מעכשיו הוא רץ לבד כל ערב.

## הגדרות רשות (Settings → Secrets and variables → Actions → Variables)

| שם | ברירת מחדל | הסבר |
|---|---|---|
| `START_TIME` | `09:00` | שעת כניסה מוקדמת ביותר |
| `START_JITTER_MIN` | `20` | טווח אקראי בדקות אחרי שעת הכניסה |
| `DAY_LENGTH` | `9:00` | אורך יום העבודה |
| `RUN_WINDOW` | `20:00-21:00` | חלון הזמן של הריצה היומית |
| `PROJECT_CODE` | (מהשבוע שעבר) | קוד פרויקט קבוע |
| `HOME_DAYS` | (מהשבוע שעבר) | ימי עבודה מהבית, למשל `mon,wed` |
| `HOME_TEXT` / `OFFICE_TEXT` | `בית` / `לקוח` | הטקסט בהערה לימי בית / משרד (רק כש-`HOME_DAYS` מוגדר) |

לבדוק איך דיווחת ימים קודמים (קריאה בלבד): **Run workflow** ← בשדה *inspect dates* כותבים תאריכים, למשל `2026-11-02 2026-11-03`.
