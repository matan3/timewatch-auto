# דיווח שעות אוטומטי ל-TimeWatch

הסקריפט רץ כל יום בימים א'-ה' בשעה 19:07 (שעון חורף; 20:07 בשעון קיץ) על השרתים של GitHub.
הוא נכנס ל-TimeWatch וממלא כל יום עד היום שמסומן "חסרה כניסה/יציאה".

- ימים שכבר דיווחת בהם היעדרות (חופש, מחלה) לא מסומנים כחסרים, ולכן הסקריפט לא נוגע בהם. **תדווח חופש/מחלה באפליקציה לפני 19:00.**
- ימים עתידיים אף פעם לא מתמלאים.
- אם משהו נכשל, GitHub שולח לך מייל.

## הגדרות (Settings → Secrets and variables → Actions)

**Secrets** (חובה):
| שם | מה לשים |
|---|---|
| `TW_COMPANY` | מספר חברה |
| `TW_EMPLOYEE` | מספר עובד |
| `TW_PASSWORD` | סיסמה |

**Variables** (רשות):
| שם | ברירת מחדל | הסבר |
|---|---|---|
| `START_TIME` | `09:00` | שעת כניסה |
| `END_TIME` | ריק | שעת יציאה קבועה. אם ריק – כניסה + מספר השעות ש-TimeWatch מצפה לו באותו יום |
| `DEFAULT_HOURS` | `9:00` | אורך יום אם לא הצליח לקרוא את התקן |

## הרצה ידנית / בדיקה
Actions → TimeWatch daily report → Run workflow.
כשהאפשרות "Dry run" מסומנת, הוא רק מראה מה היה מדווח ולא משנה כלום.
