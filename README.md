# דיווח שעות אוטומטי ל-TimeWatch

הסקריפט רץ בימים א'-ה' בשעה אקראית בין 20:00 ל-21:00 על השרתים של GitHub.
הוא נכנס ל-TimeWatch וממלא כל יום עד היום שמסומן "חסרה כניסה/יציאה".

- ימים שכבר דיווחת בהם היעדרות (חופש, מחלה) לא מסומנים כחסרים, ולכן הסקריפט לא נוגע בהם. **תדווח חופש/מחלה באפליקציה לפני 20:00.**
- ימים עתידיים אף פעם לא מתמלאים.
- אם משהו נכשל, GitHub שולח לך מייל.

## הגדרות (Settings → Secrets and variables → Actions)

**Secrets** (חובה):
| שם | מה לשים |
|---|---|
| `TW_COMPANY` | מספר חברה |
| `TW_EMPLOYEE` | מספר עובד |
| `TW_PASSWORD` | סיסמה |

**מה הוא ממלא:** כניסה בשעה אקראית בין 09:00 ל-09:20, יציאה בדיוק 9 שעות אחרי.
פרויקט קבוע (`PROJECT_CODE` בקובץ ה-workflow). מיקום: "בית" בימי שני ורביעי, "לקוח" בשאר הימים (`HOME_DAYS`).

**Variables** (רשות):
| שם | ברירת מחדל | הסבר |
|---|---|---|
| `START_TIME` | `09:00` | שעת כניסה מוקדמת ביותר |
| `START_JITTER_MIN` | `20` | טווח אקראי בדקות אחרי שעת הכניסה |
| `DAY_LENGTH` | `9:00` | אורך יום העבודה |
| `RUN_WINDOW` | `20:00-21:00` | חלון הזמן שבו הריצה היומית מתבצעת |

## הרצה ידנית / בדיקה
Actions → TimeWatch daily report → Run workflow.
כשהאפשרות "Dry run" מסומנת, הוא רק מראה מה היה מדווח ולא משנה כלום.
